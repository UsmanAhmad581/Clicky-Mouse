# Clicky Mouse

Clicky Mouse is a fast-paced Unity arcade game built around quick reactions, precision clicking, and score-based challenge gameplay. The main objective is simple: click the right targets as they appear, avoid the wrong ones, and keep your streak going as the challenge intensifies.

This project is designed as a fun and engaging click-to-score experience with colorful objects, smooth gameplay feedback, particle effects, and a clean arcade-style interface. It demonstrates core game mechanics such as object spawning, difficulty progression, UI updates, score tracking, and interactive hit detection.

## Game Overview

In Clicky Mouse, players are presented with multiple objects on screen, and they must identify the correct target to click. Each successful click increases the score, while mistakes can reduce momentum or disrupt the run. The game encourages speed, accuracy, and focus, making it an entertaining reflex challenge.

## Features

- Fast reaction-based gameplay
- Randomized target generation
- Score and progress tracking
- Multiple difficulty levels
- Particle explosion effects for successful hits
- Clean and polished Unity environment
- Simple but addictive arcade gameplay loop
